# SplatoonInkPrototype

A Unity prototype for Splatoon-style ink gameplay.

## Current scope

- Inkable floor and wall surfaces
- Basic raycast weapon emitter
- Runtime ink stamping and sampling
- Player movement modifiers based on ink ownership
- Prototype third-person camera with mouse-driven orbit and obstruction handling

## Controls

- `WASD`: move
- `Mouse`: rotate camera
- `Mouse Wheel`: zoom camera
- `Left Mouse`: fire ink

## Notes

This project is currently focused on validating the core gameplay loop before moving to more advanced rendering, swim/refill behavior, and polish.
